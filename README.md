# txt2qr

输入文字或链接，即时生成二维码的极简单页应用。

页面只有两样东西：上面一个胶囊状搜索输入框，下面一个正方形二维码。没有标题、没有按钮、没有多余的文字和选项，电脑和手机都是同一列布局。

## 使用

### 本地打开

直接用浏览器打开 `index.html` 即可，无需安装、无需启动服务器。

注意：`index.html` 和 `js/` 目录要放在一起，页面引用的是本地的 `js/qrcode.min.js`，只拷走 `index.html` 一个文件会无法生成二维码。

### 在线访问

仓库 Settings → Pages → Source 选择 main 分支根目录，发布后访问地址为：

`https://pandamo.github.io/txt2qr/`

### 预填内容

链接后加参数可直接预填输入框并生成：

- `index.html?text=https://example.com`
- `index.html?q=https://example.com`

## 功能

- 输入后自动生成，无需点任何按钮；清空输入框后二维码同步消失
- 输入框为 `type="search"`，自带系统原生清除按钮，点清除后二维码立即跟着清空
- 单行输入，最多 2000 字；内容过长无法生成时，输入框下方会提示“内容过长，请缩短后再试”
- 电脑和手机同一列布局，页面最大宽度 480px，二维码始终保持正方形、跟随容器宽度缩放
- 二维码在本地生成，输入内容不上传服务器、不经过任何后端

## 保存二维码

页面上没有下载按钮。如需保存，可用浏览器自带方式：手机上长按二维码保存图片，电脑上右键保存图片，或直接截图。

## 界面

- 黑色背景（`#000`）
- 胶囊状白色单行输入框，圆角 `999px`
- 白底黑码的正方形二维码，圆角 `16px`

## 纠错级别

纠错级别不在页面上显示，默认中（M）。如需修改，改 `index.html` 里的 `ERROR_CORRECTION_LEVEL` 变量即可，代码里有注释说明：

| 取值 | 级别 | 约可恢复的损坏比例 | 特点 |
| --- | --- | --- | --- |
| `L` | 低 | 7% | 容量最大 |
| `M` | 中（默认） | 15% | 默认 |
| `Q` | 较高 | 25% | 容错更强 |
| `H` | 高 | 30% | 容错最强，容量最小 |

## 文件结构

```
txt2qr/
├── index.html        # 页面全部内容：结构、样式、生成逻辑
├── js/
│   └── qrcode.min.js # 本地二维码库
└── README.md         # 本说明
```

## 技术说明

- 单页应用，样式内联于 `index.html`，无构建步骤
- 二维码库为本地文件 `js/qrcode.min.js`，由 npm 包 `qrcode@1.5.4` 打包而来；页面不引用任何 CDN 上的 JS、CSS 或字体，离线打开本地文件也能用
- 生成逻辑：输入变化后约 180ms 自动调用 `QRCode.toCanvas` 生成，生成分辨率为 1024，颜色为深色 `#141414`、浅色 `#ffffff`
- 尺寸处理：`canvas` 标签本身不写 `width` / `height` 属性；因为二维码库生成时会把 canvas 的内联样式写成 `1024px`，盖掉 CSS 导致手机端溢出显示不全，所以生成回调里会立即把 `canvas.style.width` / `canvas.style.height` 改回 `100%`，显示尺寸跟随容器，画布 1024 的分辨率本身不受影响
